# Шпаргалка: командная строка Linux

Основа: Bandit 0–12 (разделы 1–9). Разделы 10–12 добавлены на вырост: процессы, SSH, сеть и cron из Bandit 13–22 и недель 3–4 месяца 1.

**Как читать:** `слово` в обратных кавычках набирается как есть, **курсив** обозначает то, что нужно подставить. Ключи можно склеивать: `ls -la` = `ls -l -a`.

## 1. Навигация и файлы

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`pwd`|Показывает текущую папку. `-P` реальный физический путь (без симлинков), `-L` логический путь|
|`ls`|Список файлов. `-l` подробно (права, владелец, размер, дата), `-a` все файлы, включая скрытые (с `.`), `-A` скрытые, но без `.` и `..`, `-h` размеры читаемо (КБ/МБ), `-t` сортировка по времени, `-S` по размеру, `-r` в обратном порядке, `-R` рекурсивно по подпапкам, `-d` свойства самой папки, а не её содержимого|
|`cd` _папка_|Перейти в папку. `cd ..` на уровень выше, `cd ~` или просто `cd` в домашнюю, `cd -` вернуться в предыдущую папку, `-P` перейти по реальному пути симлинка|
|`cat` _файл_|Вывести содержимое файла целиком. `-n` пронумеровать все строки, `-b` нумеровать только непустые строки, `-A` показать невидимые символы (табуляции `^I`, концы строк `$`), `-s` сжать подряд идущие пустые строки|
|`less` _файл_|Постраничный просмотр больших файлов (аналог: `more`). Внутри: `/текст` поиск вперёд, `?текст` поиск назад, `n`/`N` следующее/предыдущее совпадение, `g`/`G` в начало/конец файла, `q` выход|
|`touch` _файл_|Создать пустой файл или обновить время изменения существующего. `-t YYYYMMDDhhmm` задать конкретную дату/время, `-c` не создавать новый файл, если его нет|
|`echo` _текст_|Вывести строку в терминал. `-n` не добавлять перенос строки в конце, `-e` включить обработку спецсимволов (`\n` перенос, `\t` табуляция)|
|`file` _файл_|Определить формат **по содержимому**, а не по расширению. `-i` вывести MIME-тип, `-b` краткий вывод без имени файла, `-z` заглянуть внутрь сжатого архива|
|`stat` _файл_|Подробная метаинформация о файле: права, UID/GID владельца, размер, время доступа и изменения. `-c` задать формат вывода (например, `stat -c "%a %n"` выведет права цифрами и имя)|
|`cp` _что_ _куда_|Копировать файлы. `-r` / `-R` рекурсивно для папок, `-p` сохранить права, владельца и время, `-i` спрашивать перед перезаписью, `-v` подробный вывод процесса, `-u` копировать только более новые файлы|
|`mv` _что_ _куда_|Переместить или переименовать. `-i` спрашивать перед перезаписью, `-f` перезаписывать без вопросов, `-n` не перезаписывать существующие файлы, `-v` показывать ход работы|
|`rm` _файл_|Удалить файл. `-r` рекурсивно удалить папку со всем содержимым, `-f` принудительно без вопросов, `-i` запрашивать подтверждение на каждый файл, `-v` выводить имена удаляемых файлов|
|`mkdir` _папка_|Создать папку. `-p` создать всю цепочку вложенных папок без ошибок, `-m` сразу задать права (например, `mkdir -m 700 папка`)|
|`ln` _цель_ _ссылка_|Создать ссылку на файл. `-s` символическая ссылка (ярлык, работает и для папок), `-f` перезаписать существующую ссылку|
|`which` _команда_|Показать полный путь к исполняемому файлу команды. `-a` показать все совпадения в `$PATH`, а не только первое|
|`history`|История введённых команд. `-c` очистить историю текущей сессии, `!N` повторить команду под номером N, `!!` повторить последнюю команду, `Ctrl+R` интерактивный поиск по истории|
|`clear`|Очистить экран терминала (горячая клавиша: `Ctrl+L`)|
|`man` _команда_|Открыть руководство по команде (`/` для поиска внутри, `q` выход). Краткая справка: _команда_ `--help` или `-h`|

**Особые обозначения:** `~` домашняя папка, `.` текущая, `..` родительская, `/` корень.

## 2. Файлы с «неудобными» именами

|   |   |
|---|---|
|**Проблема**|**Решение**|
|Имя начинается с `-`|`cat ./-файл` или `cat -- -файл` (иначе `-` воспринимается как ключ команды)|
|В имени пробелы|`cat "имя с пробелами"` или экранирование `cat имя\ с\ пробелами`|
|Скрытый файл (начинается с `.`)|Виден только при добавлении ключа `-a` (например, `ls -la`)|
|Длинное имя или спецсимволы|Начни печатать первые символы и нажми `Tab`: оболочка автодополнит имя|

## 3. Пользователи и права доступа

`ls -l` показывает 10 символов, например `-rw-r--r--`:

|   |   |   |   |   |
|---|---|---|---|---|
|**Позиция**|**1**|**2–4**|**5–7**|**8–10**|
|Что значит|тип (`-` файл, `d` папка, `l` ссылка)|владелец (user)|группа (group)|остальные (other)|

Права: `r` чтение = 4, `w` запись = 2, `x` исполнение = 1. Сумма даёт цифру на одну категорию.

|   |   |   |
|---|---|---|
|**Число**|**Символьная запись**|**Смысл**|
|`644`|`rw-r--r--`|Владелец читает и пишет, остальные только читают|
|`640`|`rw-r-----`|Владелец читает и пишет, группа читает, остальным ничего|
|`600`|`rw-------`|Только владелец. Обязательно для приватных SSH-ключей|
|`755`|`rwxr-xr-x`|Владелец всё, остальные читают и запускают|
|`750`|`rwxr-x---`|Владелец всё, группа читает и запускает, остальным ничего|

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`whoami`|Показать имя текущего эффективного пользователя|
|`id`|Показать UID, GID и все группы пользователя. `-u` только UID, `-g` только основной GID, `-G` все ID групп, `-n` выводить имена вместо чисел (например, `id -un`)|
|`groups` _user_|Показать список групп текущего или указанного пользователя|
|`su` _user_|Переключиться на другого пользователя. `-` или `-l` полный вход с загрузкой его окружения и домашней папки, `-c` _команда_ выполнить одну команду и вернуться, `-s` _шелл_ указать оболочку|
|`sudo` _команда_|Выполнить команду от имени суперпользователя (`root`). `-l` показать разрешённые для запуска команды, `-u` _user_ запустить от имени конкретного пользователя, `-i` открыть интерактивную оболочку `root`|
|`chmod` _права_ _файл_|Изменить права доступа. Числом (`chmod 640`) или символами (`chmod u+x`). Буквы: `u` владелец, `g` группа, `o` остальные, `a` все; `+` добавить, `-` убрать, `=` задать точно. `-R` рекурсивно для папки|
|`chown` _user:group_ _файл_|Сменить владельца и/или группу файла. `-R` рекурсивно для всей папки, `--reference=`_файл_ скопировать владельца с другого файла|

**Особые биты прав:**

- **SUID** (`s` вместо `x` у владельца: `-rwsr-xr-x`, число `4000`): файл запускается с правами владельца, а не запустившего.
    
- **SGID** (`s` вместо `x` у группы: `-rwxr-sr-x`, число `2000`): запуск с правами группы файла; для папок — новые файлы внутри наследуют группу папки.
    
- **Sticky Bit** (`t` вместо `x` у остальных: `drwxrwxrwt`, число `1000`, как у `/tmp`): удалять файлы внутри папки могут только их владельцы.
    

## 4. Поиск файлов

Общий вид: `find` _где_ _условия_. Условия объединяются по «И».

|   |   |
|---|---|
|**Условие / опция**|**Что делает**|
|`-name "*.txt"`|Поиск по имени файла (`-iname` без учёта регистра)|
|`-path "*текст*"`|Поиск по полному пути, включая имена папок (`-ipath` без учёта регистра)|
|`-type f` / `-type d` / `-type l`|Фильтр по типу: `f` обычный файл, `d` папка, `l` символическая ссылка|
|`-size 1033c`|По размеру. Суффиксы: `c` байты, `k` КБ, `M` МБ, `G` ГБ. `+1M` строго больше 1 МБ, `-1M` строго меньше 1 МБ|
|`-user` _имя_ / `-group` _имя_|По владельцу и группе файла|
|`-executable` / `-readable` / `-writable`|По правам для текущего пользователя. Отрицание через `!` или `-not` (например, `! -executable`)|
|`-perm 640`|По точным правам. `-perm -4000` найдёт SUID-файлы, `-perm -2000` SGID-файлы|
|`-mtime -1`|Изменялся менее 1 суток назад (`+7` более 7 дней назад; `-mmin -10` за последние 10 минут)|
|`-maxdepth N`|Ограничить глубину поиска N уровнями папок (`-maxdepth 1` искать только в текущей папке)|
|`-exec` _команда_ `{}` `\;`|Выполнить команду для каждого найденного файла (`{}` подставляет путь к файлу)|
|`2>/dev/null`|Скрыть ошибки доступа («Permission denied»). Ставится в самом конце всей команды|

Пример: `find / -type f -user bandit7 -group bandit6 -size 33c 2>/dev/null`

## 5. Размер и содержимое

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`du` _папка_|Размер папок и файлов на диске. `-s` показать только общий итог, `-h` читаемый формат (КБ/МБ), `-a` включить в вывод отдельные файлы, `--max-depth=1` показать размеры только на 1 уровень вглубь|
|`df`|Свободное место на примонтированных дисках. `-h` читаемый формат, `-T` показать тип файловой системы, `-i` проверить количество свободных inodes|
|`free`|Объём свободной и занятой оперативной памяти (RAM) и подкачки (swap). `-h` читаемый формат, `-m` в мегабайтах, `-s N` обновлять каждые N секунд|
|`wc` _файл_|Подсчёт строк, слов и байт. `-l` только строки, `-w` только слова, `-c` только байты, `-m` количество символов|
|`head` _файл_|Вывести начало файла (по умолчанию 10 строк). `-n N` первые N строк (`-n -5` всё, кроме последних 5 строк), `-c N` первые N байт|
|`tail` _файл_|Вывести конец файла (по умолчанию 10 строк). `-n N` последние N строк (`-n +5` вывести начиная с 5-й строки до конца), `-c N` последние N байт, `-f` следить за добавлением новых строк в реальном времени (для логов)|
|`strings` _файл_|Извлечь читаемые текстовые строки из бинарного файла. `-n N` минимальная длина строки (по умолчанию 4), `-e l` искать строки в кодировке UTF-16LE (часто в Windows-бинарниках)|

|                        |                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Команда**            | **Что делает и основные опции**                                                                                                                                                                                                                                                                                                                                                                                              |
| `grep` _шаблон_ _файл_ | Поиск строк по шаблону. `-i` без учёта регистра, `-v` инвертировать (строки **без** совпадения), `-n` показать номера строк, `-c` посчитать количество совпавших строк, `-r` рекурсивно по папке, `-o` вывести только совпавший фрагмент, `-E` расширенные регулярные выражения, `-w` искать только целое слово, `-l` вывести только имена файлов, `-C N` показать N строк контекста вокруг совпадения (`-A` после, `-B` до) |

Пример: `tr 'a-z' 'A-Z' < файл`                                                                                                                                                                        |

| `xargs` _команда_      | Превращает строки из стандартного ввода в аргументы для указанной команды. `-n N` передавать по N аргументов за раз, `-I {}` подставлять аргумент в место `{}`, `-d '\n'` считать разделителем только перенос строки                                                                                                                                                                                                         |

## 7. Конвейеры, перенаправление и управление задачами

|   |   |
|---|---|
|**Знак / команда**|**Что делает и основные опции**|
|`\|`|Конвейер (pipe): передаёт стандартный вывод (`stdout`) левой команды на стандартный вход (`stdin`) правой|
|`>`|Перенаправить стандартный вывод (`stdout`) в файл, **полностью перезаписав** его|
|`>>`|Дописать стандартный вывод (`stdout`) в конец существующего файла|
|`<`|Подать содержимое файла на стандартный вход (`stdin`) команды (нужно для `tr`)|
|`2>`|Перенаправить только поток ошибок (`stderr`). `2>/dev/null` выбросить все ошибки в «чёрную дыру»|
|`&>` или `> файл 2>&1`|Перенаправить и обычный вывод (`stdout`), и ошибки (`stderr`) в один файл|
|`;`|Выполнить команды строго по очереди независимо от того, успешно ли завершилась предыдущая|
|`&&`|Выполнить вторую команду **только если** первая завершилась успешно (код возврата `0`)|
|`\||`|Выполнить вторую команду **только если** первая завершилась с ошибкой (код возврата не `0`)|
|_команда_ `&`|Запустить команду асинхронно в **фоновом режиме**, сразу освободив терминал|
|`Ctrl+C` / `Ctrl+Z`|`Ctrl+C` прервать (убить) текущую команду; `Ctrl+Z` приостановить (усыпить) её|
|`jobs`|Показать список фоновых и приостановленных задач в текущей сессии. `-l` вывести также PID процессов|
|`fg` / `bg`|`fg %N` вернуть задачу №N на передний план; `bg %N` возобновить приостановленную задачу №N в фоне|

Частый шаблон подсчёта повторов: `sort файл \| uniq -c \| sort -rn`

## 8. Кодирование, хеши и сжатие

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`base64` _файл_|Кодирует в base64 (это **не** шифрование). `-d` декодировать обратно, `-w 0` отключить перенос строк каждые 76 символов|
|`xxd` _файл_|Создать hex-дамп файла. `-r` собрать бинарный файл обратно из hex-дампа, `-p` сплошной hex без адресов и ASCII-колонки, `-c N` число байт в строке|
|`md5sum` / `sha256sum` _файл_|Вычислить контрольную сумму (хеш) файла. `-c` _файл_хешей_ автоматически проверить целостность файлов по списку|
|`tar` _ключи_ _архив_|Работа с tar-архивами. `-c` создать архив, `-x` распаковать, `-t` показать список файлов внутри, `-f` _файл_ указать имя архива, `-v` подробный вывод, `-z` сжать/разжать через gzip (`.tar.gz`), `-j` через bzip2 (`.tar.bz2`), `-J` через xz (`.tar.xz`), `-C` _папка_ распаковать в указанную директорию|
|`gzip` _файл_|Сжать в `.gz` (исходный файл удаляется). `-d` разжать, `-k` сохранить исходный файл, `-c` вывести результат в `stdout`, `-9` максимальное сжатие|
|`bzip2` _файл_|Сжать в `.bz2`. `-d` разжать, `-k` сохранить исходный файл, `-c` вывести результат в `stdout`|
|`xz` _файл_|Сжать в `.xz`. `-d` разжать, `-k` сохранить исходный файл, `-c` вывести результат в `stdout`|
|`unzip` _файл.zip_|Распаковать `.zip` архив. `-l` посмотреть список файлов без распаковки, `-d` _папка_ распаковать в указанную папку, `-P` _пароль_ указать пароль|

**Важно:** у `gzip`, `bzip2` и `xz` расширение файла должно совпадать с форматом, поэтому часто нужен `mv`. Определяй формат командой `file` после **каждого** шага, пока не дойдёшь до текста.

## 11. SSH и сеть (Bandit 13–22, месяц 1, недели 3–4)

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`ssh` _user_`@`_хост_|Подключение по SSH. `-p` _порт_ указать порт (не двоеточием!), `-i` _ключ_ вход по приватному ключу (права на ключ должны быть `600`), `-L` _лок_порт:хост:порт_ локальный проброс порта, `-D` _порт_ поднять SOCKS-прокси, `-v` режим отладки, `-o StrictHostKeyChecking=no` не спрашивать подтверждение отпечатка хоста|
|`ssh` _user_`@`_хост_ _команда_|Выполнить одну команду на удалённом сервере и сразу отключиться|
|`scp` _откуда_ _куда_|Копирование файлов поверх SSH (например, `scp -P 2220 file user@host:/tmp/`). `-P` _порт_ (заглавная `-P`!), `-i` _ключ_, `-r` рекурсивно для папок, `-p` сохранить права и время|
|`nc` _хост_ _порт_|Netcat — универсальная сетевая утилита (TCP/UDP). Без `-l` работает как **клиент** (подключается к порту). Ключи: `-l` режим **сервера** (слушать порт), `-p` _порт_ задать локальный порт, `-v` подробный вывод, `-n` не резолвить DNS (работать только с IP), `-u` использовать UDP вместо TCP, `-w N` таймаут ожидания в секундах, `-4` / `-6` принудительно IPv4 или IPv6, `-z` сканирование портов без отправки данных|
|`openssl s_client`|Подключение к порту поверх TLS/SSL. `-connect` _хост:порт_ адрес и порт, `-quiet` убрать технический вывод о сертификатах, `-ign_eof` не обрывать связь сразу после конца ввода|
|`nmap` _цель_|Сканер портов и служб. `-p` _порты_ диапазон (`-p 80,443`, `-p 31000-32000`, `-p-` все 65535 портов), `-sV` определить версии служб, `-sC` запустить стандартные скрипты проверки, `-sT` TCP connect-сканирование (без root), `-sS` SYN-сканирование (нужен root), `-sU` UDP-сканирование, `-Pn` не пинговать хост перед проверкой, `-oN` _файл_ сохранить отчёт в файл|
|`diff` _файл1_ _файл2_|Сравнение двух файлов построчно. `-u` унифицированный формат (с `+` и `-`), `-y` вывести два файла рядом в два столбца, `-i` игнорировать регистр, `-w` игнорировать пробелы, `-r` рекурсивно сравнить две папки|
|`ip` _объект_|Управление сетью. `ip a` (`addr`) IP-адреса и состояние интерфейсов, `ip r` (`route`) таблица маршрутизации и шлюз по умолчанию, `ip l` (`link`) состояние интерфейсов (UP/DOWN), `ip n` (`neigh`) ARP-таблица|
|`ping` _адрес_|Проверка доступности узла по ICMP. `-c N` отправить N пакетов и остановиться, `-i N` интервал в секундах, `-W N` таймаут ответа. Порядок диагностики: `127.0.0.1` → шлюз → `8.8.8.8` → доменное имя|
|`ss`|Просмотр сетевых сокетов и открытых портов (аналог устаревшего `netstat`). `-t` TCP, `-u` UDP, `-l` только слушающие (`LISTEN`), `-p` показать имя процесса и PID, `-n` не переводить порты и IP в имена, `-a` все сокеты, включая активные соединения|
|`dig` _домен_ _тип_|Запрос DNS-записей (`A`, `AAAA`, `MX`, `NS`, `TXT`). `+short` вывести только краткий ответ, `@8.8.8.8` опросить конкретный DNS-сервер, `AXFR` попытка передачи всей зоны, `-x` _IP_ обратный DNS-запрос (альтернатива: `nslookup`)|
|`traceroute` _адрес_|Показать маршрут прохождения пакетов по узлам. `-n` не резолвить DNS-имена узлов (быстрее), `-I` использовать ICMP вместо UDP, `-T` использовать TCP|
|`curl` _URL_|Передача данных по HTTP/HTTPS и др. `-I` только HTTP-заголовки (`HEAD`), `-i` заголовки вместе с телом ответа, `-L` следовать по редиректам (301/302), `-X` _МЕТОД_ (`POST`, `PUT`, `DELETE`), `-d` _данные_ тело POST-запроса, `-H` _заголовок_ добавить HTTP-заголовок, `-u` _user:pass_ базовая авторизация, `-k` игнорировать ошибки SSL-сертификата, `-o` _файл_ сохранить ответ в файл, `-s` тихий режим|
|`wget` _URL_|Скачивание файлов по HTTP/HTTPS/FTP. `-O` _файл_ сохранить под заданным именем, `-P` _папка_ сохранить в указанную папку, `-q` тихий режим, `-c` докачать прерванный файл, `-r` рекурсивное скачивание|
|`tcpdump`|Захват и анализ сетевого трафика. `-i` _интерфейс_ (`eth0`, `lo`, `any`), `-n` не резолвить IP и порты, `-w` _файл.pcap_ записать трафик в файл для Wireshark, `-r` _файл.pcap_ прочитать сохранённый дамп, `-A` показать содержимое пакетов в ASCII, `-c N` поймать ровно N пакетов|

## 12. Планировщик Cron и повышение привилегий (Bandit 20–22)

### Где лежат все конфигурации Cron в Linux

|   |   |
|---|---|
|**Путь / команда**|**Назначение и особенности**|
|`/etc/crontab`|Главный системный файл расписания. В каждой строке после времени обязательно указывается **имя пользователя**, от которого запускается команда|
|`/etc/cron.d/`|Папка для модульных системных конфигов от разных программ и служб (именно сюда чаще всего кладут задания в Bandit и CTF). Формат строк такой же, как в `/etc/crontab` (с колонкой пользователя)|
|`/etc/cron.hourly/`<br><br>  <br><br>`/etc/cron.daily/`<br><br>  <br><br>`/etc/cron.weekly/`<br><br>  <br><br>`/etc/cron.monthly/`|Папки со **скриптами** (не crontab-таблицами!), которые система автоматически запускает каждый час, день, неделю или месяц от имени `root` через утилиту `run-parts` (имена файлов не должны содержать точек)|
|`/var/spool/cron/crontabs/`|Папка с персональными crontab-файлами пользователей в Debian/Ubuntu (в RHEL/CentOS — `/var/spool/cron/`). Доступна для чтения только `root` и владельцу|
|`/etc/anacrontab`|Конфигурация `anacron` — планировщика, который запускает пропущенные периодические задачи (ежедневные/еженедельные), если сервер или ПК был выключен в нужное время|
|`/etc/cron.allow` и `/etc/cron.deny`|Списки контроля доступа: определяют, каким пользователям разрешено или запрещено создавать свои задачи через `crontab`|
|`/var/log/syslog` или `/var/log/cron`|Системные журналы выполнения cron. Позволяют отследить, какие команды запускаются каждую минуту (полезно, если сам файл конфигурации скрыт от чтения)|

### Управление пользовательским Crontab

|   |   |
|---|---|
|**Команда**|**Что делает и основные опции**|
|`crontab -l`|Вывести список запланированных задач текущего пользователя|
|`crontab -e`|Открыть файл задач текущего пользователя в текстовом редакторе для редактирования|
|`crontab -r`|Удалить все задачи текущего пользователя (`-i` запросить подтверждение перед удалением)|
|`crontab -u` _user_ `-l`|Посмотреть задачи другого пользователя (требуются права `root`)|

### Формат строк и спецсимволы времени

1. **В пользовательском `crontab -e` (5 полей времени + команда):** `мин час день_месяца месяц день_недели команда`
    
2. **В системных `/etc/crontab` и `/etc/cron.d/*` (5 полей времени + пользователь + команда):** `мин час день_месяца месяц день_недели пользователь команда`
    

- **Допустимые значения:** минуты (`0–59`), часы (`0–23`), день месяца (`1–31`), месяц (`1–12`), день недели (`0–7`, где `0` и `7` — воскресенье).
    
- **Спецсимволы:** `*` любое значение («каждый»), `*/5` шаг каждые 5 единиц (`*/5 * * * *` = каждые 5 минут), `1,15,30` перечисление, `1-5` диапазон.
    
- **Готовые псевдонимы вместо 5 звёздочек:** `@reboot` (один раз при загрузке ОС), `@hourly`, `@daily` (`@midnight`), `@weekly`, `@monthly`, `@yearly` (`@annually`).
