
# IPv4 Addressing and Subnetting

## Subnetting Practice

IP address: 192.168.15.130/21

- Subnet mask: 255.255.248.0
- Network address: 192.168.8.0
- Broadcast address: 192.168.15.255
- First usable host: 192.168.8.1
- Last usable host: 192.168.15.254
- Usable hosts: 2046

## Calculation

Host bits: 32 - 21 = 11

Block size: 256 - 248 = 8

Third octet range: 8-15

Usable hosts: 2^11 - 2 = 2046
